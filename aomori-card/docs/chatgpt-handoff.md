# ChatGPT への引き継ぎ資料(あおもりカードメーカー)

この資料は、キャラクター画像(ローディング用マスコット)を ChatGPT に作ってもらうためのものです。
上から順に、コピーして ChatGPT のチャットに貼ってください。

## 1. アプリの概要(最初にこれを貼ると伝わりやすい)

```
「あおもりカードメーカー」は、写真・名前・地域(青森県の市町村)を入れると、ランダムなランクの
トレーディングカード風の画像を作れるWebアプリです(非公式・個人制作)。
読み込み中にスマホ画面の真ん中で、くるくる回ったり揺れたりするマスコットキャラクターが必要です。
そのキャラクターの画像を、これから一緒に作ってください。
```

## 2. 共通ルール(最初に1回貼る)

```
これから「あおもりカードメーカー」というWebアプリの、ローディング用マスコットを作ります。
まだ絵は描かないでください。次の共通ルールを記憶して、「わかりました」とだけ返してください。

【用途】スマホ画面の真ん中で、くるくる回ったり揺れたりするキャラクター。
【雰囲気】やさしい・かわいい・元気。フラットな塗り、太めでやわらかい輪郭線、ぷっくりしたシンプルな形。
【構図】正面向き。全体がひとつの塊で見える単純な形。画像の中心に置き、まわりに余白を十分にとる。
【顔】黒い小さな目、赤み(ピンク)のほっぺ、にっこり口。
【背景】透明のPNG。透明にできない場合は単色のマゼンタ(#FF00FF)。影や床は描かない。
【サイズ】正方形 1024 × 1024 px。
【禁止】文字・ロゴ・数字・県章・紋章・旗は入れない。実在するキャラクター(ゆるキャラ、企業キャラ、アニメ・ゲームのキャラ)に似せない。実在の人物にも似せない。
【色】使う色は5色前後に抑える。メインカラーはキャラごとに指定する。
```

## 4. 基準のキャラが決まったあと(同じチャットで、基準の画像を添付して頼む)

### ポーズ違い

```
添付した画像のキャラを基準にします。顔の形・色・線の太さ・質感を変えず、ポーズと表情だけ変えてください。
共通ルール(透明背景・1024×1024・正面向き・文字なし)はそのままです。
① びっくりした表情(目を大きく、口をあける)
② よろこぶ表情(目を細めて笑う、少し跳ねる感じ)
それぞれ1枚ずつ、別々の画像で出してください。
```

### ロゴ用(小さいアイコン)

```
添付した画像のキャラを基準にします。ヘッダーとボタン用の小さいアイコンを作ってください。
顔と、キャラを特徴づける部分(鉢巻・葉っぱなど)だけを大きく見せる。細かい飾りは省略し、小さくしてもつぶれないように。
透明背景、正方形 512×512、文字なし。
```

### SNSシェア用画像(OGP)

```
添付した画像のキャラを基準にします。SNSでURLを貼ったときに表示される、横長の画像(1200×630)を作ってください。
左にキャラ、右は文字を入れるための空白(文字はこちらで後から入れるので、文字は描かないでください)。
背景は水色と白のやさしいグラデーション。ねぶたや波の模様を少しだけ添えても良いです。
県章・ロゴ・文字は入れないでください。
```

## 5. 納品のお願い(ファイル名とサイズ)

| ファイル名 | サイズ | 形式 | 使い道 |
|---|---|---|---|
| `front.png` | 1024 × 1024 px | 透過PNG | オープニング。基本のキャラ(正面向き) |
| `shake.png` | 1024 × 1024 px | 透過PNG | ガチャ待ち(びっくり表情など) |
| `logo.png` | 512 × 512 px | 透過PNG | ヘッダーとボタンの小さいアイコン |
| `ogp.png` | 1200 × 630 px | PNG | SNSでURLを貼ったときの画像 |

## 6. 受け取り後のチェック

- 文字・数字・ロゴ・アイコンがどこにも入っていない
- 青森県の県章・県のロゴ・公式マスコットに似ていない
- 既存のキャラクター(ゆるキャラ・企業キャラ・アニメ・ゲーム)に似ていない
- 背景が透明(またはマゼンタ一色)で、影や床がない
- 顔や葉っぱが縁で切れていない
- ポーズ違いでも同じキャラに見える
- 利用規約上、商用利用・公開ができる(使う時点の最新の規約を確認する)
