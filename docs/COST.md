# 納品時のお客様側コスト（運用費）

> 前提：LINE公式アカウント・Google Cloud・Supabase はすべてお客様名義で契約し、各社からお客様へ直接請求される。
> 金額は概算（税抜）で、公式料金ページでは未確認。見積もり提示前に各社の最新料金を必ず確認すること。

## 1. 初期費用（外部サービス分）

| 項目 | 費用 |
|---|---|
| LINE公式アカウント開設 | 0円 |
| LINE Developers（Messaging API・LINEログイン） | 0円 |
| Google Cloud アカウント開設 | 0円（クレジットカード登録が必要） |
| Supabase アカウント開設 | 0円 |
| 独自ドメイン（任意） | 年1,500〜3,000円程度 |

外部サービスへの初期費用は実質0円。構築費・設定代行費は開発費として別途見積もる。

## 2. 月額費用の内訳

### ① LINE公式アカウント（主なコスト）
| プラン | 月額 | 月の送信上限 |
|---|---|---|
| コミュニケーション | 0円 | 200通 |
| ライト | 5,000円 | 5,000通 |
| スタンダード | 15,000円 | 30,000通（超過分は1通あたり約3円以下の従量課金） |

利用者1人あたりの月間送信数の目安：**約40〜60通**
- 1回目：30通（毎日必ず送る）
- 2回目：0〜30通（1回目で回答しない日が多い人ほど増える）
- 通知者への通知：未回答だった日 × 通知者数（通常はわずか）
- 「確認しました」の返信は Reply 送信のため無料

### ② サーバー・DB
| 項目 | 小規模 | 備考 |
|---|---|---|
| Cloud Run | 0円 | 数百人規模までは無料枠内の見込み |
| Cloud Scheduler | 0円 | 3ジョブまで無料。今回は1ジョブ |
| Supabase | 0円（Free）／約4,000円（Pro、$25） | 本番納品では Pro を推奨（Free は自動バックアップなし・一時停止あり） |

## 3. 利用者数別の月額目安（お客様負担の合計）

| 利用者数 | LINEプラン | LINE | DB | サーバー | 合計/月 |
|---|---|---|---|---|---|
| 〜4人（試験運用） | コミュニケーション | 0円 | 0円（Free） | 0円 | 0円 |
| 〜4人（本番） | コミュニケーション | 0円 | 約4,000円（Pro） | 0円 | 約4,000円 |
| 〜100人 | ライト | 5,000円 | 約4,000円 | 0円 | 約9,000円 |
| 〜500人 | スタンダード | 15,000円 | 約4,000円 | 0〜数百円 | 約19,000円 |
| 1,000人 | スタンダード＋従量 | 約60,000円 | 約4,000円 | 数百円 | 約65,000円 |

利用者が5人を超えると無料プランでは足りなくなり、ライトプラン（月5,000円）への切り替えが必要になる。ここが最初のコストの壁。

## 4. 費用を抑える工夫
- 登録完了の案内を LINE に送らず、LIFF 画面上の表示だけにして Push を節約する
- 2回目の送信を利用者ごとに ON/OFF できるようにする
- 管理画面に今月の送信数を表示し、上限の80%で警告を出す

## 5. 見積もり時に別途検討する項目（開発側の売上部分）
- 初期構築費（開発、LINE設定の代行、本番デプロイ）
- 保守費（障害対応、LINE API の仕様変更への追従、バックアップ確認）
- サポート窓口・運用代行
- 利用規約・プライバシーポリシーの作成
