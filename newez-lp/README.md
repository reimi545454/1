# NeweZ 法人向け 田んぼオーナー制度 LP（コーディングの土台）

Figma（PC 1440px / SP 390px）をもとにした静的LP。HTML + CSS + 最小限のJS + PHP（フォーム送信）。
※ 未公開・未デプロイ。`<meta name="robots" content="noindex">` を入れてあります（公開時に削除）。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（文言・画像枠・差し替えコメント） |
| `assets/css/style.css` | スタイル。冒頭の「デザイントークン」で色・フォント・余白・文字サイズを一括管理 |
| `assets/js/form.js` | フォームのブラウザ側入力検証 |
| `submit.php` | フォーム送信処理（メール送信 → `thanks.html` へ遷移）。ブルーベリーLPの方式を踏襲 |
| `thanks.html` | 送信完了ページ |
| `assets/img/` | 画像置き場（現在はfaviconのみ） |

## ローカルでの表示確認
```bash
cd newez-lp
php -S 127.0.0.1:8000        # フォーム送信（submit.php）まで確認できる
# 表示だけなら: python3 -m http.server 8000
```
ブラウザで http://127.0.0.1:8000/ を開く。ローカルにはメール送信環境がないため、
`submit.php` の最後（メール送信）は失敗扱い（500）になります。メール送信は本番サーバーで確認してください。
（フォントは Google Fonts から読み込むため、ネット接続が必要です）

## 修正のしかた
- **配色・フォント・余白・文字サイズ**: `style.css` 冒頭の `:root`（`--tanbo-*` はFigma変数と同名）。文字サイズはSP値が基本、1024px以上でPC値に上書き。
- **文言**: `index.html` を直接編集（セクションごとにコメントで区切り済み）。
- **画像差し替え**: `index.html` の各 `.placeholder` を `<img>` に置き換える。
  推奨サイズ・縦横比は各箇所のコメントに記載。枠の縦横比は CSS の `.media--xxx` が維持するので、画像が差し替わってもレイアウトは崩れません。
- **URL未確定の箇所**（捏造せず `data-todo` 付きの仮リンクにしてあります。`href` を足せばリンクになります）:
  `grep -rn "TODO" index.html` / `grep -rn "data-todo" index.html` で一覧できます。
  - 日本経済新聞・月刊「石垣」の掲載記事URL（`nikkei-article-url` / `ishigaki-article-url`）
  - プライバシーポリシーURL（フォーム内・フッター）
  - 会社情報URL（フッター）
- **お客様の声**: 仮掲載（「○口申込（従業員数○人）」「コメント掲載予定」）。実際の内容が確定したら該当カードのみ差し替え。感想は創作しないこと。

## お問い合わせフォーム
- 方式: ブルーベリーLPと同じ「`<form action="submit.php" method="POST">` → PHPでメール送信 → `thanks.html`」。
- 項目: 必須＝会社名・ご担当者名・メールアドレス・個人情報の同意 / 任意＝電話番号・配布予定人数・ご希望の用途・小分け・包装のご希望・お問い合わせ内容。
- 検証: ブラウザ側（`form.js`）とサーバー側（`submit.php`）の二重。ハニーポット（`website`）、ヘッダインジェクション対策、選択式の許可リスト照合あり。
- 項目を増減する場合は `index.html` / `form.js` / `submit.php` の3か所を揃える。

### 公開前に必ず確認（未確認・未設定）
1. **`submit.php` の宛先・送信元・件名**: ブルーベリーLPの設定（info@newez-farming.jp ほか）をそのまま引き継いでいます。この制度の問い合わせ先として正しいか確認し、必要なら冒頭の「設定」を変更。
2. **本番サーバーでのメール到達確認**（`mb_send_mail` / sendmail 設定、迷惑メール判定）。ローカルでは未確認。
3. **計測タグ**: ブルーベリーLPの `thanks.html` にある GTM / GA4 / Meta Pixel は、同じIDを使ってよいか未確認のため入れていません（`thanks.html` 内のコメント参照）。
4. スパム対策はハニーポットのみ。必要に応じて reCAPTCHA / Turnstile 等を追加。
5. プライバシーポリシー本文・URL、自動返信メールの文面。

## Figmaとの差異・要確認メモ
- **参加費・数量**: Figma PC版は「25万円（税別）／1口」「240kg／1口」、SP版は「○万円／1口」「○kg／1口」と食い違い。未確定条件を確定させないため **「○」の仮表示のまま**にしています。確定後 `index.html` の `.terms__value` を書き換え。
- **電話番号**: Figma PC版のラベルは「必須」、SP版は「任意」。依頼どおり **任意** としました。
- **メディア「石垣」**: Figma PCは実画像2枚（紙面＋表紙）、SPは仮枠1枠。今回は写真を入れない方針のため、PCは2枠・SPは1枠の仮枠にしています。
- **ゴールド文字（eyebrow）**: Figmaの `#b69a55` は白地で約2.6:1と読みづらいため、文字用に `--tanbo-gold-text: #84702f` を追加。Figma通りにするなら `--tanbo-gold` を指定。
- **フォーム見出し（07）**: Figmaどおりゴシック体（他の見出しは明朝体）。揃えるなら `.section-title--sans` を外す。
- **Figmaにある「選択肢：…」注記**はデザイン上の説明と判断し、実際の `<select>` の選択肢として実装（画面には表示しない）。
- ファーストビューの「社員と、その家族の食卓を支える。」は、メリットを強く伝えるため太字にしています。
- 日経の引用元表記に掲載日（2025年10月9日）を追記。
