# NeweZ 法人向け 田んぼオーナー制度 LP（コーディングの土台）

Figma（PC 1440px / SP 390px）をもとにした静的LP。HTML + CSS + 最小限のJS + PHP（フォーム送信）。
※ 未公開・未デプロイ。`<meta name="robots" content="noindex">` を入れてあります（公開時に削除）。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体（文言・画像枠・差し替えコメント） |
| `assets/css/style.css` | スタイル。冒頭の「デザイントークン」で色・フォント・余白・文字サイズを一括管理 |
| `assets/js/form.js` | フォームのブラウザ側入力検証 |
| `assets/js/tracking.js` | 計測タグ（Meta Pixel / GA4 / GTM）。IDを入れると有効化 |
| `submit.php` | フォーム送信処理（メール送信 → `thanks.html` へ遷移）。ブルーベリーLPの方式を踏襲 |
| `estimate.html` | 「簡単お見積もり」ページ（LPのボタンから遷移。フォーム項目はLPと同じ） |
| `thanks.html` | 送信完了ページ |
| `assets/img/` | 画像置き場（現在はfaviconのみ） |

## ローカルでの表示確認
```bash
cd newez-lp
php -S 127.0.0.1:8000        # フォーム送信（submit.php）まで確認できる
# 表示だけなら: python3 -m http.server 8000
```

`submit.php` の最後（メール送信）は失敗扱い（500）になります。メール送信は本番サーバーで確認してください。

## お問い合わせフォーム
- 方式: ブルーベリーLPと同じ「`<form action="submit.php" method="POST">` → PHPでメール送信 → `thanks.html`」。
- 項目: 必須＝会社名・ご担当者名・メールアドレス・個人情報の同意 / 任意＝電話番号・配布予定人数（従業員数）・配布予定kg数（白米）・ご希望の用途・小分け・包装のご希望・お問い合わせ内容。
- **人数を入力したらkg数も必須**（form.js と submit.php の両方で検証）。数字は全角でも入力可（半角に直して処理）。
- 検証: ブラウザ側（`form.js`）とサーバー側（`submit.php`）の二重。ハニーポット（`website`）、ヘッダインジェクション対策、選択式の許可リスト照合あり。
- 項目を増減する場合は `index.html` / `estimate.html` / `form.js` / `submit.php` を揃える。

### 自動返信（口数・概算予算の自動計算）
- 「配布予定人数」と「配布予定kg数」が**両方入力された人**の自動返信には、次の文面と内訳が入ります。
  「お問い合わせありがとうございます。大体◯口が必要で、ご予算は◯◯円（税別）です。営業担当より3営業日以内にご連絡いたします。」
- 計算（`submit.php` 冒頭の「設定」で変更）:
  - 口数 ＝ ⌈ kg数 ÷ 216 ⌉（1口＝216kg。216kgちょうどは1口、216.5kgは2口）
  - 参加費 ＝ 口数 × 250,000円（税別）
  - 小分け手数料 ＝ 配布予定人数 × 1,000円（税別／税込1,100円）。**「小分け・包装のご希望」が「2kg・3kg・5kg」「450g贈答用」のときだけ加算**（「通常30kg袋」「オリジナル包装」「相談して決めたい」「未選択」は加算なし）
  - 予算（合計） ＝ 参加費 ＋ 小分け手数料
- 例: 50人・300kg・2kg・3kg・5kg → 2口 / 500,000円 ＋ 50,000円 ＝ **550,000円（税別）**
- 片方しか入力されなかった場合は、金額なしの自動返信（「担当者よりご案内いたします」）になります。
- 社内向けメールにも同じ計算結果が入ります。

### 簡単お見積もり（estimate.html）
- LPの3と4の間に「簡単お見積もりはこちら」ボタン → `estimate.html`（LPと同じ項目の別フォーム）。
- 受信メールで区別: 件名が「【NeweZ LP｜簡単お見積もり】…」、本文に「流入元：簡単お見積もり（estimate.html）経由」。LP経由は「【NeweZ LP】法人向け田んぼオーナー制度 お問い合わせ」。
- 送信完了後は `thanks.html?from=estimate` へ。計測（Lead）にも `estimate` / `lp_form` を付けて区別できます。

### 公開前に必ず確認（未確認・未設定）
0. **料金・計算の前提（要確認）**: 参加費25万円／1口、1口216kg、小分け1袋1,000円（税別）は依頼時のご指定。小分けの袋数は「配布予定人数＝袋数（1人1袋）」と仮定しています。違う場合は `submit.php` の `estimate_for()` を修正。LP上の「参加費」表示は引き続き「○万円／1口」の仮表示のままです（`index.html`）。
1. **`submit.php` の宛先**: 問い合わせは `info-ricefield@newez-farming.jp` に届く設定（自動返信の返信先も同じ）。送信元（From）の `noreply@newez-farming.jp` と件名はブルーベリーLPから引き継いだ値なので、サーバーで送信できるアドレスか確認（冒頭の「設定」で変更）。
2. **本番サーバーでのメール到達確認**（`mb_send_mail` / sendmail 設定、迷惑メール判定）。ローカルでは未確認。
3. **計測タグ（このLP専用のIDを設定）**: ブルーベリーLPとは別に新規作成したMeta Pixel（必要ならGA4・GTMも）のIDを `assets/js/tracking.js` の `TRACKING` に貼る。未設定（空）の間は何も読み込まず、計測されません。LPは PageView、`thanks.html` は PageView + Lead（GA4は generate_lead）を送信。ブルーベリーLPのIDは区別のため入れないこと。
4. スパム対策はハニーポットのみ。必要に応じて reCAPTCHA / Turnstile 等を追加。
5. プライバシーポリシー本文・URL、自動返信メールの文面。

## Figmaとの差異・要確認メモ
- **参加費・数量**: 自動返信では 25万円（税別）／1口・216kg／1口 を使用（ご指定）。LP上の表示は未更新。Figma PC版は「25万円（税別）／1口」「240kg／1口」、SP版は「○万円／1口」「○kg／1口」と食い違い。未確定条件を確定させないため **「○」の仮表示のまま**にしています。確定後 `index.html` の `.terms__value` を書き換え。
- **電話番号**: Figma PC版のラベルは「必須」、SP版は「任意」。依頼どおり **任意** としました。
- **メディア「石垣」**: Figma PCは実画像2枚（紙面＋表紙）、SPは仮枠1枠。今回は写真を入れない方針のため、PCは2枠・SPは1枠の仮枠にしています。
- **ゴールド文字（eyebrow）**: Figmaの `#b69a55` は白地で約2.6:1と読みづらいため、文字用に `--tanbo-gold-text: #84702f` を追加。Figma通りにするなら `--tanbo-gold` を指定。
- **フォーム見出し（07）**: Figmaどおりゴシック体（他の見出しは明朝体）。揃えるなら `.section-title--sans` を外す。
- **Figmaにある「選択肢：…」注記**はデザイン上の説明と判断し、実際の `<select>` の選択肢として実装（画面には表示しない）。
- ファーストビューの「社員と、その家族の食卓を支える。」は、メリットを強く伝えるため太字にしています。
- 日経の引用元表記に掲載日（2025年10月9日）を追記。
