# 聖地巡礼マップ Japan

日本国内のアニメ・漫画・映画・ドラマの聖地を地図で探せる静的Webアプリ。ビルド不要、任意の静的ホスティング(GitHub Pages / Netlify / S3 等)にそのまま配置できます。

## 機能
- 地理院タイル(標準/淡色/写真)とOSMの切替、表示範囲を日本に制限
- ジャンル・都道府県・訪問状況・キーワードで絞り込み、ピンのクラスタ表示
- 現在地から近い順の並べ替え(日本国外では無効)
- 訪問済みの記録(ブラウザのlocalStorage、サーバー送信なし)
- スポットごとの共有リンク(`#スポットID`)、地図アプリ連携
- スマホ対応、ダークモード対応、CSP設定済み、外部CDN不使用(Leaflet同梱)

## ローカル起動
```
cd seichi-map && python3 -m http.server 8000   # http://localhost:8000
```

## スポットの追加
`data/spots.json` の `spots` に追記し、`node scripts/validate.mjs` で検証します
(ID重複・都道府県名・ジャンル・日本国外の座標を検出。CIでも実行)。

## 注意
- 座標は概算です。公開前に各スポットを公式情報で確認してください。
- 作品名・キャラクター名の利用や画像掲載は権利者のガイドラインに従ってください(本アプリは画像を含みません)。
